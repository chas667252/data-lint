# data-lint

给一张 CSV 做数据质量体检。**零依赖、单文件、可以直接当 CI 门禁。**

它不修数据，只负责在上游数据变成下游事故之前，把问题摆到桌上。

```
python data_lint.py orders.csv
```

---

## 为什么需要它

数据管道里最贵的故障不是报错，是**静默错误**。

报错五分钟就能修好；静默错误要两周后老板觉得"这个数字不太对"才会被发现，而这两周里的报表全是错的。

最常见的触发方式就是一个大小写：

```sql
-- 上游某天把 'paid' 改成了 'Paid'
select sum(amount) from orders where status = 'paid';   -- 那天的订单全丢了
```

任务没失败、日志没报错、看板也没有任何提示。数字只是安静地错了。

`data-lint` 做的事，就是把"同一列里同时存在 paid / Paid / PAID"这种事实，在你写 SQL 之前告诉你。

## 快速开始

```bash
# 1. 什么都不用装，直接跑
python data_lint.py orders.csv

# 2. 指定主键，才会检查主键冲突
python data_lint.py orders.csv --key order_id

# 3. 机器可读 / 给人看
python data_lint.py orders.csv --json > report.json
python data_lint.py orders.csv --html report.html
```

要求 Python 3.10+，**不需要 pip install 任何东西**。

> **Windows 用户**：双击 `demo.bat`，会依次跑单元测试、干净样例、脏样例并生成 HTML 报告，一次看完。

## 检查项

| 类别 | 检查内容 | 对应的事故 |
|---|---|---|
| 结构 | 表头为空 / 重复列名 / 行列为空 / 列数不一致 | 上游导出失败，给了只有表头的文件 |
| 类型 | 数值列混入非数值、文本列混入数字 | `"abc"` 混进金额列，整列退化为文本，`SUM` 结果为 0 |
| 完整性 | 每列空值率、空字符串与 NULL 混用 | 关键字段缺失，聚合结果偏低 |
| 唯一性 | 主键冲突、完全重复的行 | 主键重复导致 join 后数据翻倍 |
| 一致性 | 大小写、首尾空格、日期格式、小数位、千分位、前导零 | `paid` / `Paid` 导致筛选漏数 |
| 分布 | min / P50 / P95 / max、3×IQR 极端值、大量 0 值 | 某天金额全变成 0，均值被悄悄拉低 |

## 当 CI 门禁用

退出码是设计过的，可以直接接管道：

| 退出码 | 含义 |
|---|---|
| `0` | 没有严重问题，可以继续 |
| `1` | 存在严重问题，应该阻断 |
| `2` | 文件或参数错误（路径不存在、`--key` 列名写错） |

```yaml
- name: 数据体检
  run: python data_lint.py data/orders.csv --key order_id
```

数据质量检查之于数据管道，如同单元测试之于代码。

## 设计取舍

这些是写这个工具时做的判断，不是随手写的：

- **只提示，不修复。** 修数据是不可逆操作，工具只负责报告。删一行数据需要人签字，不是脚本能决定的事。
- **主键必须由人指定（`--key`）。** 工具猜不出哪一列是主键，猜错就会把正常的外键重复报成事故。它只会在结尾提示"哪几列看起来像主键"。
- **极端值用 3×IQR，不用 1.5。** 小样本上 1.5 倍会把正常的长尾业务值全标成异常。**告警一旦不准，就没人看了**，宁可漏报。
- **日期格式只认 ISO 系。** 不猜 `03/04` 是 3 月 4 日还是 4 月 3 日——猜错比不猜更危险。
- **单文件、零依赖。** 拷贝一个 `.py` 就能用，不需要虚拟环境。能用 `python xxx.py` 解决的事，不该让人先配环境。
- **健康分是启发式的。** 权重（严重 15 / 警告 5 / 提示 1）是人拍的，不是精确指标，所以报告里明写"仅供参考"。把它当 KPI 就会有人去刷分。

## 已知限制

- 只做**单表**检查，不做跨表关联校验（外键一致性是另一类工具）。
- 需要人指定主键，不会自动推断。
- 全部数据读进内存，超大文件请用 `--max-rows` 先抽样。
- 编码自动探测只覆盖 utf-8 / gbk / latin-1；其他编码用 `--encoding` 显式指定。
